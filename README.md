# YouTube Creator-Editor Collaboration Platform

A web platform where YouTube creators and editors can collaborate on video uploads and reviews.

## Features

- User authentication (Creators and Editors)
- YouTube channel connection
- Workspace management with role-based access control
- Video upload and review system
- Timestamped comments for feedback
- Version comparison for videos
- Direct publishing to YouTube
- Notification system

## Tech Stack

- **Frontend**: React.js
- **Backend**: Node.js with Express
- **Database**: Firebase Firestore
- **Authentication**: Firebase Authentication with Google OAuth
- **Storage**: Firebase Storage
- **Hosting**: Firebase Hosting

## Project Structure

```
├── client/             # React frontend
└── server/             # Node.js backend
```

## Setup Instructions

### Prerequisites

- Node.js and npm
- Firebase account
- Google Developer account (for YouTube API)

### Installation

1. Clone the repository
2. Install dependencies for both client and server
3. Set up Firebase project and configure environment variables
4. Run the development servers
